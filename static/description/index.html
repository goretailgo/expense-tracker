Expense Tracker

Multi-city monthly Income & Expense tracking, with City → Manager → Director approval

One simple monthly form per city. Predefined income/expense lines, "+ Add Income" / "+ Add Expense" for anything extra, automatic totals, a Draft → Submitted → Approved workflow, and roll-up reporting from City to Manager to Director — all enforced server-side with Odoo security groups and record rules. No files, receipts, or attachments required.
